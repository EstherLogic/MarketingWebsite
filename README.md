# Marketing Website

A clean, modern, multi-page website built with **HTML5** and **CSS3**. The project features a simple navigation bar, a polished layout, and a consistent visual style across all pages.

## Pages

- **Main** — A welcoming landing page with a navigation menu and interactive-looking action buttons.
- **Images** — An image gallery with captions and a section for discovering new ideas.
- **Agent** — An introduction page with descriptive text and a blue illustration panel.

## Built With

- HTML5
- CSS3
- Google Fonts — Inter

## Project Structure

```text
MarketingWebsite/
├── index.html
├── index.css
├── images.html
├── images.css
├── agent.html
├── agent.css
└── logo.png
```

> If your logo file has a different name or extension, update the file name in this structure and in the HTML favicon link.

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/EstherLogic/MarketingWebsite.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No build tools or package installation are required.

## Navigation

Use the navigation menu at the top of each page to move between **Main**, **Images**, and **Agent**.

## Notes

- This is a static front-end project.
- The layout is built without CSS Flexbox or Grid.
- Some gallery images may load from external image URLs and therefore require an internet connection.
